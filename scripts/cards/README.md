# Demo feeding cards

For the most reliable live demo, print one high-contrast card per label:
`love`, `good`, `great`, `joke`, `fact`, `garbage`, and `spam`.

Save a reference photo of each card in this folder as `<label>.png`.
Give each card a clearly different coloured border. The webcam feeder finds the large card and compares its average colour to these references. It falls back to OCR when EasyOCR is installed.
